# Changelog

## 1.1.0

- Added supplier-scoped portal access, incidents, notifications, customer demand requests, and supplier inquiries.
- Added FEFO dispatch with conditional atomic stock decrements and compensating rollback.
- Added batch quality and purchase data, soft deletes, migration, supplier scorecards, reorder insights, and audit-log APIs.
- Added security middleware, Zod validation, structured logging, health checks, graceful shutdown, and Swagger UI.
- Added React Query-backed incident, demand, notification, portal, and detail views.
- Added backend and frontend tests, lint/format scripts, architecture/API docs, and Docker/CI assets.
